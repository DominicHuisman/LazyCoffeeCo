# Images Directory

Place your image files here:

## Recommended Images

### Logo
- `logo.png` - Main logo file (the sage green Lazy Coffee Co. logo)

### Hero Background
- `hero-bg.jpg` - Background image for the hero section (optional)

### Gallery
Create a `gallery/` subfolder for testimonial/event photos:
- `gallery/photo1.jpg`
- `gallery/photo2.jpg`
- etc.

## Image Guidelines

- **Format**: JPG for photos, PNG for logos/graphics
- **Size**: Optimize images for web (under 500KB each)
- **Dimensions**: 
  - Logo: 200px height recommended
  - Gallery: 400x400px (will be cropped to square)
  - Hero background: 1920x1080px
